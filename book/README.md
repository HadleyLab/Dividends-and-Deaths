# Dividends & Deaths — Book Governance

## What This File Is

This README is the **governance manual** for *Dividends & Deaths*.

It defines the book-level contracts that make the manuscript writable as a **system** rather than a linear narrative. If prose, concepts, or protocols conflict with this directory, **this directory wins**.

This file is written to be read by:
- the author
- collaborators and editors
- future versions of the system

It explains *how this book holds itself together*.

---

## Purpose

To define the **invariants** that must remain stable across drafts so the book can scale without meaning drift.

These invariants ensure that:
- lived experience does not become memoir
- theory does not become abstraction
- emotion does not outrun mechanism
- death is treated as a systems outcome, not a mystery

---

## How This Book Is Written (Symbiotic Human Computation)

This book is written using **symbiotic human computation**: a governed partnership between human judgment and machine-assisted reasoning.

The human author contributes two orthogonal inputs:

### 1. Lived Episodes & Cases

The author injects:
- witnessed episodes (e.g., UCSF, Elena, Hyojung)
- clinical or historical cases (e.g., Atul, father)
- personal lived experience rendered directly in prose

These provide **witness, consequence, and moral authority**.

### 2. Formal Concept Construction

The author also constructs:
- system-level concepts (e.g., Geometry of Medicine)
- structural models (Engines, Gears)
- governance constructs (Digital Māyā, Ma’at)

These provide **structure, constraint, and causal clarity**.

These inputs are intentionally orthogonal.

They are reconciled through **governance and ledgers**, not intuition.

AI is used to:
- test consistency
- surface contradictions
- compress language
- enforce reuse and contracts

AI does **not** supply authority, witness, or moral judgment.

This allows the manuscript to function like a **well-oiled system** rather than a fragile narrative.

## Digital Māyā and Ma’at (Operational Balance)

This book assumes representational power is unavoidable.

- **Digital Māyā** names the condition where representations begin to govern action.
- **Ma’at** names the enforceable constraint that binds representation to consequence.

The system is designed so:
- Māyā is never eliminated
- Ma’at is never optional

Equilibrium is enforced through contracts, ledgers, and protocols.

## Author–System Contract

- The author supplies meaning, witness, and responsibility.
- The system supplies structure, memory, and enforcement.
- Neither replaces the other.

Episodes without governance become memoir.
Concepts without episodes become abstraction.

This directory exists to prevent both failures.

---

## Non-Negotiables

- Governance documents override prose.
- Death is never treated as accidental or mysterious.
- Grief is permitted only after structure is explicit.
- Every chapter must trace harm to engine failure.

If a chapter "feels right" but violates these rules, it is wrong.
