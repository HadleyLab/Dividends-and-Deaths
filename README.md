# Dividends & Deaths — Publication Workspace

## Purpose
Provide a governed, system-first workspace for writing *Dividends & Deaths* without meaning drift.

## Scope
Applies to all canonical governance, concepts, protocols, chapters, and ledgers in this repository.  
Drafts are explicitly non-canonical.

## Related Documents
- `AUTHORING_PLAN.md` — end-to-end authoring lifecycle
- `book/README_BOOK.md` — book governance and authority map
- `concepts/README_CONCEPTS.md` — canonical ontology and concept rules
- `protocols/README_PROTOCOLS.md` — execution protocols and checks
- `chapters/README_CHAPTERS.md` — governed chapter bundle rules
- `drafts/README_DRAFTS.md` — non-canonical exploration space

## Non-Negotiables
- Governance overrides prose.
- Concepts override narrative when conflicts arise.
- Death is always traceable to system failure.
- Grief is permitted only after structure is explicit.

If the system blocks progress, fix the input—do not bypass the system.

## Update Triggers
- repository purpose or invariants change
- directory structure or canonical order changes
- authoring plan changes

- Ledger precedes prose

---

## Minimal Chapter Recipe
1. Read `book/spine.md` for Chapter Question, Claim, Exit Handoff.
2. Build `chapter_NN_ledger.md`.
3. Register assets via `protocols/protocol_asset_registration.md`.
4. Check constraints via `protocols/protocol_canon_compliance.md`.
5. Draft `chapter_NN_prose.md` from the ledger.
6. Update `chapter_NN_scene.md` to map scenes to asset IDs.

If prose introduces unledgered material, it is wrong.

## AI Usage (Bounded)
AI is used to enforce consistency, surface contradictions, compress language, and check reuse.  
AI does not supply authority, witness, or moral judgment.

## Author–System Contract
- The author supplies meaning, witness, and responsibility.
- The system supplies structure, memory, and enforcement.
- Neither replaces the other.
