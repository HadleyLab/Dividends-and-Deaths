# Access

## Purpose
Define access as the system condition that permits care to occur.

## Scope
Applies to passages describing whether care can be reached, scheduled, or delivered.

## Category
Policy Context

## Canonical Definition
Access is the condition that allows a person to enter the system and receive care.
It is shaped by coverage, geography, time, language, and institutional rules.

## Usage / Placement Rules
- Use when describing barriers to care that occur before clinical action.
- Tie access failures to downstream delays and outcomes.

## Relationship to Canonical Concepts
- **Coverage:** access often depends on coverage but is not identical to it.
- **Legibility:** access determines whether a person can become legible to the system.
- **Mortality as Ledger:** access failures surface as delayed diagnosis and death.

## Reusable Phrase (Canonical)
“Access determines whether care can occur at all.”

## Death-Bound Clarification
When access is blocked, the system never sees the person in time.  
The result is delayed or absent intervention and preventable mortality.
