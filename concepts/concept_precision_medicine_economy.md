# Precision Medicine Economy

## Purpose
Define the system that monetizes coded biological and clinical data.

## Scope
Applies to chapters that describe value flow, extraction, and structural asymmetry.

## Category
System Primitive

## Canonical Definition
The precision medicine economy is the multi-trillion-dollar system built on extracting value from coded biological and clinical data.  
It includes genomics, pharma, imaging, AI, EHRs, insurers, and data brokers.

## Usage / Placement Rules
- Use when describing value flow, dividends, and system incentives.
- Frame in terms of representation and custody, not innovation.
- Avoid treating it as a purely scientific project.

## Relationship to Canonical Concepts
- **Billable Code:** the economic unit the system runs on.
- **Three Engines:** discovery, care, and information execute the economy.
- **Digital Māyā:** representation outranks the body as the system scales.
- **Ma’at:** governance constraint required to prevent lethal drift.

## Reusable Phrase (Canonical)
“The precision medicine economy runs on representation before it runs on care.”

## Death-Bound Clarification
When the economy optimizes for scalable representation without custody, it concentrates dividends upstream and distributes deaths downstream.  
Mortality becomes the audit trail of the system’s incentives.
