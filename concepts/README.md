# Concepts

## Purpose
Define the core ideas, terms, and lenses that must stay consistent across the book.

## Scope
Applies to all chapters and protocols.

## Chapter Bundle
Concept definitions support the `chapter.md`, `ledger.md`, and `scene.md` triplet used in each chapter bundle.

## Naming
- Files use `snake_case`.

## Structure
Concepts are organized as a cohesive stack:
- **Vocabulary:** canonical terms and phrases to keep language consistent.
- **Lenses:** narrative frameworks with placement rules to avoid overuse.
- **Policy:** legal and regulatory context mapped to specific chapters.

Each file defines:
- What the concept is.
- Where it appears in the chapter map.
- How to reference it without repetition.

## Index
- `concepts/concept_vocabulary.md` — canonical meanings and phrases
- `concepts/digital_maya.md` — placement rules for a representation lens
- `concepts/maat.md` — placement rules for a governance lens
- `concepts/healthcare_data_laws.md` — policy context for U.S. healthcare data
