# Open Provenance Token System

## Purpose
Define the provenance infrastructure proposed in the book.

## Scope
Applies to passages describing custody reassignment and traceable data lineage.

## Category
Governance Construct

## Canonical Definition
The Open Provenance Token System is a proposed infrastructure that encodes data lineage, consent, and value flow so representation can be audited and governed.

## Usage / Placement Rules
- Use when describing provenance infrastructure or custody reassignment.
- Treat as governance architecture, not ideology.

## Relationship to Canonical Concepts
- **Provenance:** the system operationalizes lineage.
- **Custody:** enables enforceable control of representation.
- **Ma’at:** renders governance actionable at scale.

## Reusable Phrase (Canonical)
“Provenance becomes enforceable only when it is infrastructural.”

## Death-Bound Clarification
Without enforceable provenance infrastructure, errors propagate across systems and time.  
That propagation turns misrepresentation into mortality.
