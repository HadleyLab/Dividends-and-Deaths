# Billable Code

## Purpose
Define the Billable Code as the economic unit that converts care into value.

## Scope
Applies to chapters that explain reimbursement, legibility, and how representation governs care.

## Category
System Primitive

## Canonical Definition
The Billable Code is the standardized symbolic representation that converts human care into economic value.  
It is not neutral; it is the atomic unit of the precision medicine economy.

## Usage / Placement Rules
- Capitalize when referring to the abstraction (Billable Code); use lowercase only when colloquial.
- Use when describing reimbursement, access gating, or how representation becomes action.
- Do not describe the Billable Code as a mere administrative convenience.

## Relationship to Canonical Concepts
- **Precision Medicine Economy:** the Billable Code is its economic unit.
- **Legibility:** the code is the admission ticket into the system.
- **Digital Māyā:** the code is the representation that can outrank the body.
- **Custody / Provenance:** determine who can act on and profit from codes.

## Reusable Phrase (Canonical)
“The Billable Code is the fundamental economic unit of American healthcare.”

## Death-Bound Clarification
When the Billable Code becomes the primary grammar of care, anything that is hard to code becomes hard to treat.  
That loss of representation delays or denies intervention, and mortality rises where the code thins out.
